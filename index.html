01 왜 IIDXwidget인가Why IIDXwidget

투컴 방송 지원Two-PC streaming

게임 PC에서 앱을 켜고, 방송 PC의 OBS에 게임 PC 주소만 넣으면 됩니다. IP 찾는 법부터 방화벽 허용까지 앱 안의 연결 가이드가 차근차근 안내합니다. Run the app on the game PC and put its address into OBS on the stream PC. The built-in connection guide walks you through finding the IP and allowing it through the firewall.

채터링 감지 지원Chatter detection

스위치가 튀어서 생기는 이중 인식을 건반마다 셉니다. 유독 튀는 건반만 짚어 줘서 스위치 교체 시기를 가늠할 수 있습니다. Counts double inputs from switch bounce on every key and points out the keys that stand out, so you know when a switch is wearing out.

무료Free

모든 기능을 무료로 씁니다. 결제도, 광고도, 가입도 없습니다. Every feature is free. No payment, no ads, no sign-up.

03 기능Features

실시간 입력 계기판Live input dashboard

스크래치 회전과 방향, 건반 입력을 실시간으로 그리고, 아래 계기판에 이번 세션의 타건 수와 업타임이 흐릅니다. Turntable spin and every key press, drawn live, with this session's presses and uptime on the dashboard.

가이드: 화면 구성 → Guide: what you see →

KPS 스피드미터KPS speedometer

KPS가 속도계처럼 올라가고, 빨간 영역에서는 주황에서 빨강으로 달아오르며 끝값에서 살짝 떨립니다. IIDX / BMS ~★★ / BMS ★★~ 프리셋. KPS climbs like a speedometer, heats from orange to red in the red zone and trembles at the limit. Presets for IIDX, BMS up to ★★ and ★★ and up.

가이드: KPS 스피드미터 → Guide: KPS speedometer →

릴리즈 · 롱노트Release and long notes

건반 위 숫자는 건반별, 계기판은 전체 평균 릴리즈입니다. Rag 님 위젯과 같은 규칙으로 재고, 롱노트는 평균에서 빼며 누르고 있는 동안 따로 색을 칠합니다. Per-key release above each key, overall average on the dashboard — same rules as Rag's widget. Long notes are left out and get their own color while held.

가이드: RELEASE 수치 → Guide: release value →

DP 지원DP support

1P와 2P에 컨트롤러를 각각 연결합니다. 종류가 달라도 되고, 같은 컨트롤러 두 대라면 장치를 골라 쓰면 됩니다. 위젯은 하나로 이어지고 계기판은 가운데에 붙습니다. Connect a controller to 1P and 2P separately — different models are fine, and with two identical ones you just pick each device. The widget joins into one with the dashboard in the middle.

가이드: 버튼 레이아웃과 DP → Guide: button layout and DP →

방송에 맞춰 꾸미기Make it yours

스크래치에 원하는 이미지를 넣고, 이미지에 맞춰 배경·건반·입력·글자·롱노트 색을 바꿉니다. GIF 등 움직이는 이미지도 지원하고, 회전 방향마다 다른 이미지도 됩니다. 이미지에서 어울리는 색을 알아서 뽑아 주는 추천 색상도 켤 수 있습니다. 바꾼 설정은 방송 화면에 바로 반영됩니다. Put your own image on the turntable and match the background, key, active, text and long-note colors to it. Animated images like GIFs work too, and you can use a different image per spin direction. Turn on recommended colors to have them picked from your image automatically. Changes show up on stream instantly.

가이드: 위젯 외관 → Guide: widget appearance →

채터링 감지Chatter detection

스위치가 튀어서 생기는 이중 인식을 건반마다 셉니다. 흰 건반과 검은 건반을 따로 묶어 유독 튀는 건반만 빨갛게 표시하고, Rag / Sadang 두 가지 기준 중에 고를 수 있습니다. Counts switch bounce per key. White and black keys are compared separately and only the outliers light up red. Choose between the Rag and Sadang presets.

가이드: 채터링 감지 → Guide: chatter detection →

계정을 한 번 연결하면 버튼 하나로 이번 세션의 타건 수를 서열표 사이트에 보냅니다. 끌 때 자동으로 보낼 수도 있습니다. Connect your account once, then send this session's presses with one click — or automatically when you quit.

알아서 다시 연결Reconnects on its own

앱이 꺼져 있으면 방송 화면에 안내를 띄우고, 앱을 켜는 순간 다시 붙습니다. OBS를 건드릴 필요가 없습니다. If the app is off, the stream shows a notice; start the app and it reconnects. No need to touch OBS.

내 컨트롤러도 공식 지원해 주세요Request official support

컨트롤러가 보내는 신호를 기록해서 보내주시면, 그걸로 전용 프로필을 만듭니다. 앱 안에서 몇 분이면 됩니다. Record what your controller sends and share it — that's what we build a dedicated profile from. It takes a few minutes inside the app.

  1. IIDXwidget의 메뉴 → 컨트롤러 정보 수집을 열고, 안내대로 버튼을 누르고 스크래치를 돌리며 녹화합니다. In IIDXwidget, open Menu → Controller probe and record while pressing buttons and turning the turntable as it asks.
  2. 결과 파일 저장으로 JSON 파일을 저장합니다. Press Save result file to save a JSON file.
  3. GitHub의 컨트롤러 지원 요청 이슈 양식을 열고, '수집 파일' 칸에 JSON 파일을 끌어다 놓아 첨부한 뒤 등록합니다. Open the controller support request issue form on GitHub, drag the JSON file into the 'Probe file' box, and submit.

GitHub 계정이 필요합니다. 파일이 25MB를 넘으면 ZIP으로 압축해 주세요. 요청이 곧 공식 지원을 보장하지는 않고, 실물 확인이 필요할 수 있습니다. A GitHub account is required. Zip the file if it's over 25MB. A request doesn't guarantee support, and we may need to test the hardware.
